## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host → MCP Server | Untrusted tool arguments cross here via Stdio (JSON-RPC). |
| Server → File System | Local configuration and campaign data are written to disk. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | Stdio Stream | mitigate | Use standard MCP SDK transport which handles framing/validation. |
| T-01-02 | Information Disclosure | config.json | mitigate | Force .gitignore entry for config.json (per D-07). |
| T-01-03 | Denial of Service | Tool Calls | mitigate | Implement basic error handling in tool handlers to prevent server crash. |
| T-01-SC | Tampering | npm installs | mitigate | slopcheck + blocking human checkpoint for [ASSUMED] packages. |
</threat_model>
