<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| File System → Docling | Potentially malicious PDFs/PPTXs are passed to the Docling CLI. |
| Ingestion Service → AI SDK | Large Markdown strings are passed to the LLM. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | Tampering | Path Arguments | mitigate | Sanitize all file paths in `ingest_campaign_doc` using `path.resolve` and verify they exist before calling Docling. |
| T-01-05 | Information Disclosure | Local Files | mitigate | Ensure Docling subprocess runs with restricted permissions if possible; restrict file access to the current project directory. |
| T-01-06 | Information Disclosure | LLM Prompt | mitigate | Use clear system instructions to ensure AI extraction doesn't leak sensitive data or ignore constraints. |
</threat_model>
